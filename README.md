# Rldcoin protocol development

Development uses a fresh public-fixture testnet and separately admitted regional
ground candidates, all with no monetary value. A mainnet has not launched.
Test balances, keys and custody never become mainnet assets or authority.
Obsolete mainnet materials are excluded from this project and its completion evidence.

## Current implementation and verification

The [current status](docs/PLAN_STATUS.md) records exact source versions, successful
and failed runs, cold verification and remaining gates. The exact October 4
frozen ground source passed 491 process checks, three Runtime custody phases,
the ordinary three-region owner-payment return, the original complete finite
fault scope and both strict stopped cold verifications. The final compatible
prefixes conserve 300 fixture units with no pending exports. These are same-host,
same-controller results; earlier failed sources remain failed. See the
[resource and remaining-gate matrix](docs/operations/GROUND_RESOURCE_AND_GATE_MATRIX.md).
Changed versions, sustained Byzantine/load behavior, overlapping handoffs,
independent custody and physical routes need separate qualification.

The [regional native candidate](tools/regional-ledger/README.md) implements
owner-authorized payments, conservation, independent regional finality, permanent
import deduplication, onward exports, new return imports, wallet reservations,
encrypted custody, native history replay and explicitly admitted validator epochs.
Signed admission, exact source identity and separately retained signing heads are
required. Discovered node identities and transport receipts never authorize value.

## Node mesh and asynchronous transport

The target is progressive neighbor discovery and multi-hop evidence carriage:
Earth → Proxima Centauri → Andromeda illustrates the topology, not deployed
physical routes. See [N1–N10](docs/research/INTERSTELLAR_NODE_MESH_REQUIREMENTS.md)
and the [ground contact prototype](docs/operations/INTERSTELLAR_NODE_MESH.md).
The fixture lifecycle integrates bounded pinned TLS contacts; physical contact,
causal propagation, durable custody and complete native authentication remain
distinct from local ledger acceptance and spendability.

## Completion and release

The [master plan](docs/RLDCOIN_MASTER_PLAN.md) makes A–G and all I1–I12 mandatory.
Long history, sustained faults/load, independent operations/security/custody,
cross-device recovery, cryptographic evolution and physical routes remain open.
The [fresh testnet](docs/operations/EARTH_FRESH_TESTNET.md) and
[future release path](docs/operations/EARTH_TEST_TO_MAINNET.md) describe current
qualification. A future mainnet requires a new signed zero-issuance genesis and
verified adoption. No old network material supplies that authorization.

The independent English website lives in the sibling `rldcoin-website` checkout.
