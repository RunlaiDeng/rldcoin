# Rldcoin protocol development

The goal is peer-to-peer payment across delayed regions: owner authorization,
independent recipient verification, regional autonomy during disconnection and
asynchronous evidence relay. Current development uses no-value fixture candidates.
Mainnet has not launched. Test balances, keys and custody never become monetary
assets or adoption authority.

The [frozen whitepaper](https://rldcoin.com/whitepaper),
[freeze receipt](docs/WHITEPAPER_FREEZE_RECEIPT.json),
[master plan](docs/RLDCOIN_MASTER_PLAN.md) and
[clause acceptance](docs/WHITEPAPER_IMPLEMENTATION_ACCEPTANCE.md) define the target.
[Current finite status](docs/PLAN_STATUS.md) distinguishes exact source versions,
real failures and remaining gates. A local PASS does not complete the project.

[Stable verification entries](docs/operations/VERIFICATION.md) cover Core,
[regional Native](tools/regional-ledger/README.md), standard vectors and hybrid
cryptographic candidates. Source, dependencies, stable tests and public vectors
remain public. Per-experiment records and original private custody remain locally
preserved outside the public source inventory.

Default relay belongs to the ordinary node lifecycle: authenticated discovery and
bounded durable carriage. Earth → Proxima Centauri → Andromeda illustrates topology.
[N1–N10](docs/research/INTERSTELLAR_NODE_MESH_REQUIREMENTS.md) and the
[ground prototype](docs/operations/INTERSTELLAR_NODE_MESH.md) do not prove physical
routes or ledger authority. Contact, transport receipt, complete authentication,
local finality and spendability require distinct evidence.

Independent consensus/security/custody, complete composition proofs, long-term
resource and cryptographic evolution, and real physical routes remain unqualified.
Future adoption requires a new signed zero-initial-allocation genesis and all P1–P8
gates. Protocol development does not change the frozen website or paper.
