# Security policy

This repository contains no-value development candidates. Compilation, public
vectors and local component verification do not establish monetary adoption,
independent operator custody, a full security audit or physical-route qualification.
Unknown authority, conflicting finality, stale trusted heads and invalid or
unavailable evidence must refuse the affected operation and retain original records.

## Reporting

Use [repository issues](https://github.com/RunlaiDeng/rldcoin/issues) for
non-sensitive defects. No private vulnerability reporting channel is configured
for this repository. For a sensitive finding, first obtain a private disclosure
channel designated by the maintainer; do not send the details to an unverified
address or assume GitHub private reporting is enabled.

Never put private keys, credentials, wallet/ledger files, unpublished sensitive
proofs or exploitable operational details into a public issue or pull request.
Once a disclosure channel is available, include the affected source, threat model,
minimal reproducer and practical impact without unrelated private material.
