# Security status

The fresh Earth production release is under qualification. The public [network status](https://rldcoin.com/network) states whether transfers or imports are available.

A single owner currently controls the launch validators and operational hosts. Four signatures from that owner do not establish independent governance or review. The source-finality rule prevents a conforming destination from crediting an export that can be reversed by an ordinary source reorganization, but coordinated equivocation or key compromise remains a risk. On conflicting finality evidence, source and destination value service must halt and preserve the records for an explicit public resolution.

Report security findings privately to the repository owner through GitHub's security advisory channel. Do not post live private keys, wallet files or unpublished proofs in an issue.
