# 测试网验收与全新主网上线

开发使用[独立无价值测试网](EARTH_FRESH_TESTNET.md)及单独准入的地区地面候选。
主网尚未上线。废弃主网的资料、状态、发布包和归档不再作为项目进度、价值或授权依据。

## 发布路径

1. 在准确版本和新 fixture 身份下实现并验证主计划 A–G 与 I1–I12；记录失败，不沿用其他版本的通过。
2. 完成普通支付、地区自主终局、中继、再出口与返程、完整冷重放、持续故障和容量恢复。
3. 按地区内部传播、验证、持久化、分叉和安全预算实测确定出块、成熟、争议及发行参数。加速逻辑时间不是生产性能。
4. 取得独立运营、安全复核、密钥保管、防回滚及跨设备恢复的实际证据。
5. 使用新的非测试签名身份签署高度 0、零初始发行、空历史的准确创世、规则与源码；核验实际节点、钱包、矿工和公开服务。

采用的是已验收的实现，不是测试资产或测试签名。测试密钥、奖励、余额、通道和出口永不迁入主网。
当前实现或测试通过不自动授权签署创世或宣称完整协议资格。
