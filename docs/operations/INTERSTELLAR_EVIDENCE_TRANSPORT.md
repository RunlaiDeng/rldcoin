# 跨区域异步证据运输

`tools/interstellar_transfer.py` 是有界操作层工具：固定路线、限制大小、绑定准确证据字节、持久入队，再交给原生节点验证。
运输帧 ID、发现标签或持久收据都不是价值、终局或签名授权。

每个接收节点必须验证准确货币/地区准入、完整源终局、所有者和金额、依赖、唯一导入及当地成熟。
运输收件、原生导入、成熟可花与源获知回执分别记录。断联和本机超时不能退款、删除未解决证据或释放已扣除出口。

当前开发与复现仅使用无价值测试网和单独准入的地面候选；废弃主网的资料不用于验收。
完整节点的[普通生命周期中继](INTERSTELLAR_NODE_MESH.md)须满足
[N1–N10](../research/INTERSTELLAR_NODE_MESH_REQUIREMENTS.md)。固定 TLS 的真实同机 socket 演练不等于跨主机、独立保管或物理星际路线资格。

工具局部测试只证明声明的封装/落盘/拒绝路径。当前完整周期与故障范围以
[项目状态](../PLAN_STATUS.md)中对应准确源码和终端报告为准。
