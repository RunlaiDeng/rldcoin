# Fault-copy public inspection anchors

The stopped successful three-region cycle has separately retained public carrier
and configuration anchors. The earlier full-fault controller copies that source
and rebinds private paths and operator-selected literal endpoints. Its copied
original anchors do not bind those new configurations, and its stopped verifier
opens a normal Node with an existing private identity. That observation does not
qualify the strict read-only transport gate. Retain all earlier reports/stores
without conversion or retrospective anchor creation.

The new controller requires the exact successful source report's complete twelve
public anchors before creating the fault copy. After all configured path/endpoint
rebinding and native custody checks, and before any ordinary node starts, it
retains a separate `fault-mesh-inspection-anchors.json`. Public keys/node IDs
come from the already authenticated original setup; current configuration hashes
are retained at this new trusted operator setup. The inherited anchor file is
not overwritten. Terminal reports bind both original and new anchor digests.

The stopped full-fault verifier requires that exact new report-bound inventory
and native currency before MeshInspection. It loads no private mesh identity,
initializes no transport state and grants no receipt, ledger, signing or head
adoption rights. All Native genesis, envelope, owner/value, custody/head and
complete archive authentication, stopped-process and private-byte checks remain.
Old unanchored fault reports refuse unchanged. A successful component check is
not a fresh full-profile pass, independent custody or physical qualification.

A separate controller-only candidate probes that receipt at most once per two
seconds. Skipped probes return false; no prior receipt, head, ledger or success
is cached. Every eligible probe performs the original full native read and must
match the original expectation and actual maturity/finality/quarantine checks.
Refusals propagate to the existing bounded wait. The original 600-second phase,
height 24 cap and all fault, replay and custody gates remain. Three mechanical
cases cover skipped reads, fresh rejection after an earlier result and native
refusal. Fresh full-profile evidence must establish whether this changes the
outcome; no failed fixture is restarted or copied as a value source.
