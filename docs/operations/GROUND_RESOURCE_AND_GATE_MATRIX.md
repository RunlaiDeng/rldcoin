# Resource and qualification matrix

Each gate remains mandatory. Finite same-controller observations cannot qualify independent operation or physical routes.

| 优先项 / 对应要求 | 候选能力边界 | 必须交付 |
| --- | --- | --- |
| 1 资源与持续故障负载 / I7、I8、I12 | 一个有限故障样本；此前压力失败仍失败；未给出吞吐或长期稳定性 | 对冻结基线先限定负载/接触模型、连续资源与未交付样本采集，保留签署/价值/容量边界；声明规模下独立持续故障、拒收与重启验收 |
| 2 长历史与恢复 / I10 | 有界重放、共享历史/证明及分页候选；普通/BFT 长历史未资格 | 版本化活动历史/档案与永久去重契约，超过首个 200,000 块时代的实际普通节点与钱包恢复；缺档、损坏、旧头、满盘安全拒绝 |
| 3 通用价值与终局组合 / I1–I7 | 三地区返程和一次预配不重叠时代切换；不覆盖任意来源/循环/重组 | 多来源、拆并金额、复杂依赖/重复祖先、前后终局分叉、冲突隔离及明确治理的规格、原生实现、反例和组合审查 |
| 4 独立保管与普通用户 / I9、I12 | 原生加密钱包、独立调用者头和地面浏览器候选；同控制者 | 分属独立控制者/设备的签署、支付、旧备份和断电恢复；实际 anti-rollback 与复制密钥并发；钱包状态和签前复核一致 |
| 5 长延迟密码与真实承载 / I8、I11 | IPv4 TLS 地面适配、短挑战和 90 日本地证书；不是年级链路 | 异步证据与明确验证期限、在途轮换/撤销/降级拒绝、仍有效档案续认证；真实接触容量、寿命、保管边界和路线独立实测 |
| 6 新正式采用 / A–G、I12 | 测试资产和公钥无货币价值，正式网络未授权 | 所有适用协议/独立门槛通过后，新签名零发行创世、精确公开源码/工件和独立采用；真实航路另行资格 |
