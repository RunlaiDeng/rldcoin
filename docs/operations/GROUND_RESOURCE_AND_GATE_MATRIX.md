## 实测资源与当前硬上限

下列“停止最大值”是十二节点终止快照中最大的一个节点，不能冒充全运行峰值。
活跃包数只有两个阶段样本，未知遥测保留未知。没有连续峰值、RSS、带宽、持续吞吐或百分位测量。

| 资源 | 此次观察 | 当前限制与含义 |
| --- | --- | --- |
| 运输档案文件 | 停止最大 702 | 每档案 4,096 文件；所有保留对象及失败残留计入，不能删证据腾出承诺容量 |
| 运输档案字节 | 停止最大 73,815,666 字节 | 每档案 256 MiB；不含完整节点、钱包、Native/签署头、TLS 等资源，不能称为单节点总存储 |
| BFT 合并存储 | 停止最大 2,313,626 字节 | 索引加共享完整快照仍受 32 MiB 限制；摘要不能替代 Native 验证 |
| BFT 完整信封 | 停止最大 176 | 512 信封、每信封 64 快照引用；旧证据不剪除，满载拒绝新准入 |
| 活跃运输包 | 两个阶段采样最大 31 | 活跃准入 256；32 为完成项归档高水位，未获回执的在途项仍活跃 |
| 承载与接收 | 原批次和接收槽未变 | 每 payload 3 MiB，原两入站槽内至多一个未确认延迟输入；排队不是保管或账本权利 |
| Native 逻辑历史 | 本次各区最大高度 15 | 原逻辑 8 MiB、256 块/活动段及 64 检查点限制保留；不证明超过首个 200,000 块发行时代 |
| 共识与恢复时间 | 逐阶段原始观察在 JSON | 最慢导入成熟阶段 447.298 秒；单次有限成功不是持续负载 SLA、稳定余量或多年恢复预算 |

运营预算必须分别提供 CPU/RSS、磁盘及 fsync、序列化/重放、每跳带宽和断联积压成本。
若承诺准入速率 r、无服务时长 D 和突发 B，最低积压预算 rD+B 还需加副本、元数据、失败残留和安全余量；当前未测出可承诺 r。
恢复服务需超过持续新准入，容量拒绝须在承诺保管前发生，已扣除出口始终不退款。
地区验证者、无原生发行地区的矿工/终局、中继及档案服务的付费者和资金预算仍未落实；节点启动不产生奖励权。
