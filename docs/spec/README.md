# Earth protocol specifications

The [fresh Earth genesis](EARTH-GENESIS-POW.md) and [direct value adoption](EARTH-VALUE-ADOPTION.md) establish one empty height-zero chain. The [value rules](EARTH-VALUE-RULES.md) cover source mining, signed transfers, local payment channels, source exports and zero-native-issuance destination imports. [Source finality](EARTH-SOURCE-FINALITY.md) defines the four-signature checkpoint boundary. [Destination authorization](EARTH-DESTINATION-AUTHORIZATION.md) binds the second region. [Transition authorization](EARTH-TRANSITION-AUTHORIZATION.md) is an optional local record.

The exact published implementation source commitment includes these texts and the Rust execution rules. Public status is operator telemetry; independent review and operation require separate evidence. Historical compatibility and test fixtures remain identifiable inside source control but grant no value on Earth.
