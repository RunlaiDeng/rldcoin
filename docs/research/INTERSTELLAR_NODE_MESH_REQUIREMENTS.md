# 星际节点渐进发现与多跳中继要求

状态：2026-09-30 用户确认的产品与架构要求；传输层地面原型已验证，真实星际通信与价值网络未验收。本规范不修改已签创世、共识或发币权限。

## 产品目标

用户在新的地区启动节点，该节点成为网络延伸点：发现可接触邻居，经邻居逐步获知远方节点，并为其他用户中继证据。体验类比用户指定的《明日方舟：终末地》息壤中继器，仅指逐点延伸与中继的产品意图；不引用游戏的物理能力、图像或规则作为协议依据。

**默认启动要求：** 每个正常启动的完整网络节点必须在同一生命周期内启用中继，认证发现邻居、有界持久保存并自动转交其他参与者的支付证据、重启恢复队列；不得要求另起中继进程或中央注册。钱包客户端不等于完整网络节点。实际接触、身份/适配器配置和可声明的资源预算仍是前提。新节点带来的可达地区扩展、替代路径及独立承载容量分别验收；节点数本身不证明更安全、更快或必然送达。原单独启动的 contact-spool 程序保持为运输参考；通用 fixture 节点已将其纳入默认启动生命周期，已采用源/目的节点尚未具备此默认能力。

示例拓扑为 **地球 ↔ 比邻星 ↔ 仙女座星系**。地球无需直接连接仙女座，也无需一直连接某个地球中央服务器。链路可以是双向、单向、周期接触或物理携带；前向路由可用不代表回程路由可用。

“启动即可发现”以至少一个实际可接触邻居或预先提供的引导/接触端为条件。完全孤立且从未收到任何外界信号的节点不能发现其他节点。首次启动等待邻居通告和回复也受信号传播约束。“连接”在远距离下表示可重复使用的异步接触关系，不要求持续在线会话、秒级心跳或实时共同链头。

## 必须满足的规则

| 编号 | 要求 | 验收依据 |
| --- | --- | --- |
| N1 | 节点有独立、持久的身份密钥，与钱包/共识密钥分离；地区标识、协议版本、邻居通告均验签和限额 | 篡改、错身份、错网络、未知版本、重启测试 |
| N2 | 邻接接触可引导；本区发现、签名通告逐跳交换与离线携带共同实现渐进发现；无必须永远在线的地球中心 | 原生节点正常启动即启用中继；逐个加入相邻接触节点，自动扩展可达地区和候选路径 |
| N3 | 自动尝试可用下一跳，并在容量和跳数限额内转发；路径可变，有向链路与回程分别处理 | 地球→比邻星→仙女座原样传递，返回收件回执；新增可用替代路径后断开原路径仍交付；缺路保留 |
| N4 | 存储后转发；长期断联不会按几秒超时抹掉远方节点或退款 | 停中继、重启发送/接收节点、恢复续传；绝不凭时间解锁 |
| N5 | 每跳交付边界验签，转发历史绑定前一签名与指定下一跳，防改目标、缩短已签路径、循环和超跳数 | 恶意中继、路径篡改、循环和跳数边界测试 |
| N6 | 重复与乱序幂等；整份接触交换先验证并持久保存再消费接收文件或确认 TCP 保管；容量拒收保留已有和未处理证据 | 重复、损坏、容量、文件安全与失败原子性测试 |
| N7 | 候选路线、观测到的接触、已排队、目的端收件、账本验收、成熟可花分别显示 | 发现通告不能声称正在在线，收件回执不能声称到账 |
| N8 | 每个地区执行自己的账本和终局规则；多跳只传字节，任何中继都不因连接自动成为矿工、终局签名人或新发币地区 | 目的区固定真实源身份、重放、唯一导入和成熟规则；地区自报名称无价值权限 |
| N9 | 接触计划按每跳光时、容量、积压、轨迹与回程评估；非同时连通路径可用，但不承诺有限发现/交付时间 | 延迟、移动端、单向接触、失联、负载与归档实测；供应超过服务时必须拒收 |
| N10 | 星系级运行另须长期档案、密钥/算法迁移、独立运营与物理链路资格 | 地面秒级演练不能替代多年/百万年运行或外部复核 |

## 物理和价值边界

NASA 给出的地球附近距离量级为比邻星约 4.24 光年、仙女座约 250 万光年。在静止端点的简化模型里，比邻星发现新地球信息单程至少约 4.24 年；仙女座尺度为百万年。绕经中继仍受各段光时之和约束。移动目标、宇宙尺度与端点运动需要专门路线模型，不能用此量级计算充当实际交付期限。息壤式“延伸”是拓扑目标，不是超光速能力。

地球→比邻星→仙女座的一份出口证据可以只由比邻星中继原样携带，不在比邻星导入或再发行。仙女座的账本必须另外被授权验证真实地球源账本；自动发现并不建立这种授权。目的区收件后仍须重放、终局和唯一导入验证，成熟后才可花。任意地区导入后再次向第三地区输出的资产谱系、返还价值、取消与多地区终局属于独立协议工作；本原型没有实现。

## 当前交付层次

`tools/interstellar_mesh.py` 是常驻、补充的接触目录原型。它自动交换签名通告，计算有向最少跳数候选路由，持久中继 `interstellar_transfer.py` 的精确帧，并传播目的节点签名的 **仅证据收件** 回执。相邻端和接触适配器由运营者配置；发现远方通告不会自动访问任意远方 URL，也不能创造不存在的物理接触。原型无 BPv7、射频/激光链路、本地无线广播发现、NAT 穿透、接触窗口/带宽优化、恶意多数抗隔离保证、长期密钥轮换、账本自动提交或正式节点默认启用。

64 个发现节点、16 个相邻端、256 个保留消息/回执、64 MiB 状态与每端 64 MiB/256 文件、最多 16 跳是地面原型的准入限额，不是星际容量。源帧另受原有 3 MiB 载荷限制；交换最多 4 帧且实际序列化不得超过 20 MiB，公平轮询避免尾部饿死。没有自动删除保留消息；满额后必须另行制定可审计保留/归档策略。Ed25519 为现有工程签名选择，不保证百万年密码安全；本地签名身份与通告序号的备份回滚也尚无外部防回滚根。

现有已签原生源/目的节点仍只连接显式配置的本机桥；此原型须单独运行，不能宣称原生节点已自动组成星际网。现有目的服务的源刷新门槛仍需单独设计和验证长期断联自治。正式发布必须再验证真实适配器、双方身份与密钥、资源余量、跨所有者运行、旧通告/撤销传播、掉电、对抗隔离及完整价值流程。

无价值通用 fixture 普通启动另已集成默认固定 TLS 1.3 的 IPv4 TCP 地面适配，双向接触只访问独立配置/固定身份和证书的字面 IPv4 端点，不使用远方通告中的端点。实际同机套接字已验证双跳、备用路径、断线/重启、持久保管后确认、确认丢失后幂等、容量/恶意输入拒收、多批轮换与加密连接认证/拒绝降级；原生三账本 TLS 演练没有共享运输目录。三秒接入等待和 90 天当地证书有效期只约束地面通信，失败仍保留证据和已扣除价值；未验证跨设备、单向、物理链路、长期密码或独立运营，不足以满足 N1–N10 完整资格。
