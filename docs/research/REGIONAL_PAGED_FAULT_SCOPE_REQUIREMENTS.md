# Paged ordinary fault-scope entry model

This is a read-only experiment-selection contract, not signed admission or Native
ledger authority. The original Source89 six-stage ordinary cycle completed at
E9/P6/A8 under600seconds. Its full report, original signed requests, heads and5050
private files stay retained. Old failed currencies are never opened, copied,
recovered, resigned, refunded or reused.

1. Require explicit external SHA256 pins for the completed checks, stage and
   entire retained file inventory; exact Native source/implementation, actual CLI
   bytes, complete Core171 manifest and every protected Native/Python source file
   must match. A sampled Native head, renamed legacy report or loose height label
   cannot supply this provenance. All paths reject symlink ancestors and special
   files; JSON rejects duplicate fields/nonfinite numbers and bounded reads apply.
2. Require the actual clean six-phase successful report,27zero service terminals,
   three original owner responses and complete stopped/caller observations. Verify
   the retained whole inventory before and after reviewing metadata. Include orphan
   and private source bytes; never prune or rewrite them. This byte scan does not
   reauthenticate Native signatures, replay a ledger, or grant latest-state rights.
3. Require twelve ordered separate Native/voter/caller directory pins. Check the
   retained local native history head, height/currency/region/profile, original voter
   header binding and nonpending caller head against explicit retained pins. All
   heads are observations from the completed source, not independent freshness.
   All actual owner intents/heads and complete partial-approval observations remain.
4. Require the explicit paged-value admission and exact four ordered distinct keys.
   The missing-leader gate is the first successor whose parent-height modulo four
   selects the absent key. It must be strictly later than current height and within
   the original E27/P24/A24 caps and24new-height ceiling. No fixed7/4/4 or joint/role
   threshold is adopted; original600stage/60round/maturity2/three-of-four and every
   object/archive/history/wire/page bound remain.
5. Return immutable experiment scope only, with Native-authority and independent-
   freshness false. No Native/Runtime invocation, signing, private copy, migration,
   recovery, endpoint discovery or ledger mutation is part of this model. Any future
   runtime driver must first obtain full native fixed-head history/envelope/caller/
   owner authentication and check all configured transport pins under its own
   reviewed contract and distinct budget. An entry model cannot grant an executable
   permission to continue custody, reconstruct a ledger, or qualify a fault run.

The current model discriminator is once120seconds with network budget0: all
parent-height residues/cap boundaries, exact current stored scope and wrong report,
source, binary, head, custody order/layout, admission, owner, cap and pending-state
counterexamples. Negative byte-scan witnesses are clearly mechanical test inputs;
positive path reviews every actual retained file. First unexpected result or byte
change, complete discrimination or budget exits without unchanged retries.
Independent custody/rollback, full fault liveness,2016challenge/Source66 dependencies,
post64 ordinary history, physical and all normative protocol gates remain separate.

The composed preflight is a separate once120seconds/network0 scope. After that
exact reviewed entry, only `history-check --expected-head` may invoke Native,
with explicit project cwd, no private input and at most30seconds per call within
the shared deadline. Each of12complete current genesis replays must return its
exact retained head/currency/region/height and fixture/no-independent-freshness
flags. A later mismatch returns no partial inspection. Recheck all original
source bytes after the last call. One actual stale-head request must refuse.
Do not call status, bft-status, wallet-view, init or recovery: original complete
custody/envelope/owner qualifications are reused only while their exact complete
source/inventory remains unchanged. No signer or wallet journal is opened by
Native in this preflight. This does not permit network startup or qualify faults.
